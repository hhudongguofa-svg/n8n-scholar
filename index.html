个人科研自动化工具

n8n Scholar

将 Google 学术提醒整理为可阅读的研究动态。

应用用途

本工具在使用者自己的电脑上运行 n8n 工作流，在使用者授权后读取指定的 Google 学术提醒邮件，提取论文标题、作者、摘要片段和链接，通过 DeepSeek API 生成中文整理结果，并汇总为 Markdown。启用发信功能时，可发送至使用者指定的邮箱。

授权与数据

仅为已配置的工作流申请 Gmail 读取权限；需要邮件发送时另申请发送权限。邮件内容和运行数据可能保存在本机 n8n 执行记录与输出文件中。待分析的邮件正文会发送至 DeepSeek API，详见隐私政策。

阅读边界

邮件片段不等于完整摘要或论文全文。模型结果仅辅助文献筛选，应以原始论文核实。
