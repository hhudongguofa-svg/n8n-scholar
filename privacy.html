隐私政策

更新日期：2026年10月21日

1. 应用与使用范围

n8n Scholar 是由使用者本机部署的个人科研自动化工具。本政策描述 Gmail 学术提醒整理工作流。此静态网站只展示应用信息，不收集或接收邮件，也不存储 OAuth 令牌。

2. 读取的信息和用途

经使用者授权，工作流可读取匹配筛选条件的 Gmail 邮件，包括邮件 ID、主题、日期、发件人、正文及正文中的链接，用于提取论文信息、去重和生成研究简报。Google OAuth 权限可能允许读取范围大于筛选结果；筛选条件是工作流逻辑，并非 Google 授权本身的限制。

3. 第三方处理与发送

配置的工作流会将用于分析的邮件主题和正文发送至 DeepSeek API 以生成摘要。正文可能包含邮箱地址、追踪参数及其他个人信息，使用者应在发送前检查输入或配置脱敏步骤。DeepSeek 对收到数据的处理受其服务条款和隐私政策约束，本应用不承诺其保留或训练政策。若启用 Gmail 发送节点，生成的简报和附件将发送至使用者配置的收件人。

4. 存储与保留

OAuth 凭据由本机 n8n 管理，邮件数据及模型结果可能保存在 n8n 数据库、执行历史、Markdown 文件、备份和已发送邮件中。保留期限取决于本机 n8n 配置及使用者的清理操作；当前不承诺固定期限或自动删除。网页本身不包含分析脚本；GitHub Pages 托管方可能按其政策处理访问日志。

5. 控制、撤销和删除

使用者可停用工作流，在 Google 账号的第三方连接页面撤销授权，在 n8n 删除对应凭据和执行记录，并删除本机文件、备份和发送的邮件。撤销授权不会自动删除已经生成或交付的数据；第三方已接收数据的处理需按相应平台规则进行。
